# Sign Language Recognition

A web application for recognizing sign language hand gestures using a webcam.

The project was built to practice React, Node.js, Express.js, and computer vision.

## Features

- Real-time hand gesture recognition
- Webcam support
- Display recognized signs
- Simple web interface

## Technologies

- React
- Vite
- JavaScript
- Node.js
- Express.js
- MediaPipe

## Project Structure

sign-language/
├── frontend/
├── backend/
├── public/
└── README.md

## Installation

Clone the repository:

git clone https://github.com/PhanKhaiDIen/sign-language.git
cd sign-language

### Frontend

cd frontend
npm install
npm run dev

### Backend

Open another terminal:

cd backend
npm install
node server.js

## Project Goal

This project was created to learn how hand tracking and computer vision can be used in a web application.

I also used this project to improve my skills with React, Node.js, Express.js, and working with APIs.
